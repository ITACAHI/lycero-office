# Ghi Chú Phát Hành Lycero Office 1.0.2

**Ngày phát hành:** 06/10/2026

---

## Tổng quan

Phiên bản 1.0.2 tinh chỉnh quy trình đóng gói và đồng bộ phiên bản giữa các module, chuẩn bị nền tảng ổn định cho chuỗi cập nhật tiếp theo.

---

## Sửa lỗi

- **Đồng bộ phiên bản đóng gói:** Khắc phục chênh lệch phiên bản giữa `package.json` gốc (`1.0.1`) và tên file installer phát hành (`Lycero Office Setup 1.0.2.exe`). Cả hai hiện đồng bộ ở `1.0.2`.
- **Dọn dẹp artifact build lồi nhau:** Xóa thư mục `apps/shell/apps/shell/release/` sinh ra do nhầm `BUILD_DIR` lúc đóng gói thủ công. Đường dẫn build đúng là `apps/shell/release/` (đã được gitignore sẵn).

---

## Cải tiến

- **Đồng bộ `package-lock.json`:** Khóa phiên bản chính xác các gói phụ thuộc (đặc biệt là các gói `@next/swc-*` của bản build dev) để lần cài đặt kế tiếp nhất quán trên mọi máy.
- **Tag release đã chú thích:** Tag `v1.0.2` được tạo dạng annotated (có người ký + ngày), sẵn sàng cho auto-update feed.

---

## Ghi chú nâng cấp

- **Không cần gỡ cài đặt bản cũ:** Trình cài đặt NSIS sẽ tự nhận diện bản 1.0.1 đã cài và nâng cấp tại chỗ.
- **Khởi động lại sau cài đặt:** Đóng hoàn toàn ứng dụng (kiểm tra tray icon) trước khi mở lại để bảo đảm các thay đổi có hiệu lực.
- **Đường dẫn build local:** Khi chạy `npm run dist:win` thủ công, **không** set `BUILD_DIR` để tránh lỗi nested path lặp lại.
